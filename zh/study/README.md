# 学习指南
**简体中文** | [English](../../study/README.md)

与原著并行阅读的著作级指南，而非代替原著。每份指南都给出逐章（或逐节）的讲解、按编号前提重构的论证——每个论证附一条异议与一条回应——检查点问题（附文末答案），以及应避免的常见误读。使用方式遵循[学习路径](../learning-path.md)的要求：先合上书，自己重构论证，然后再与指南的重构相对照；批评永远放在第二位，切勿先行。
