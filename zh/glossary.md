# 术语表

**简体中文** | [English](../glossary.md)

各条目中出现的术语的通俗定义。每位哲学家的条目也会在其语境中解释其关键术语；本术语表是速查版本。

- **a priori / a posteriori / 先天／后天：** 无需凭借经验即可知道的（如"所有单身汉都是未婚的"）／只能通过经验才知道的（"昨天下雨了"）。康德又加上了关键的第三类：*先天综合*判断。
- **Abjection / 贱斥：** 克里斯蒂娃的术语，指对一切威胁自我与非我之界限的东西——呕吐物、污秽、敞开的伤口、尸体——的猛烈排斥，它激起的反感比单纯的不喜欢更强烈。贱斥物既不是主体也不是客体，而是人为了成为一个"我"而必须排出的东西；她认为，最先被这样排出的，是婴儿与母亲身体的融合。见[伊利格瑞、克里斯蒂娃与巴特勒](eras/05-20th-century/feminist-philosophy-after-beauvoir.md)。
- **Alienation / 异化：** 马克思的术语，指工人在资本主义下的疏离状态——与自己的劳动产品相疏离，与劳动活动本身相疏离，与自身的人类能力相疏离，也与其他人相疏离。见[卡尔·马克思](eras/04-19th-century/karl-marx.md)。
- **Actual occasion / 现实事态：** 怀特海的终极实在单位：一滴转瞬即逝的经验，它"摄受"（prehends，感受并考量）其整个过去世界，并将其统一为一个满足——随后它消亡，成为其后继者的数据。人、电子乃至空无的区域，都同样是这类事态组成的社会。见[阿尔弗雷德·诺斯·怀特海](eras/05-20th-century/alfred-north-whitehead.md)。
- **Analytic / synthetic (judgments) / 分析判断／综合判断：** 仅凭词语的意义即为真的／凭借世界的实际状况才为真的。奎因著名地抨击了这一区分本身，论证"分析的"无法不循环地加以定义。
- **Apophatic (negative) theology / 否定神学：** 通过否认我们给予上帝的每一个名称来谈论上帝的方式，因为每个名称都取自受造物，而上帝是一切受造物的原因，并非其中之一。它与*肯定*（cataphatic）之路相配，后者肯定圣经所给的名称；它的"不是"意为"超过"，而非"少于"。伪狄奥尼修斯赋予这一方法经典形式，埃克哈特则把它转向内心。见[伪狄奥尼修斯与埃克哈特大师](eras/02-medieval/pseudo-dionysius-and-eckhart.md)。
- **Archē / 本原：** 希腊语，意为起源／原理——前苏格拉底哲学家所探求的万物第一原理。
- **Ataraxia / 心灵安宁：** 心灵不受搅扰的状态；是伊壁鸠鲁派与皮浪式怀疑论者共同的*目标*，但两者通过相反的途径达到它。
- **Aufhebung (sublation) / 扬弃：** 黑格尔的术语，指一个阶段同时被取消、被保留并被提升到一个新的阶段之中。
- **Authenticity / 本真性：** 在克尔凯郭尔与海德格尔那里，指担负起自己的生存——直面自身的有限性与选择，而不是随"大众"或"常人"漂流。它不只是真诚或自我表达而已。见[马丁·海德格尔](eras/05-20th-century/martin-heidegger.md)。
- **Bad faith (mauvaise foi) / 自欺：** 萨特的术语，指对自身自由的自我欺骗——假装自己是一个固定的东西（"我别无选择；我天生就是这样"）以逃避责任。见[让-保罗·萨特](eras/05-20th-century/jean-paul-sartre.md)。
- **Biopower / 生命权力：** 福柯的术语，指施加于生命本身的现代权力——通过制度与统计来治理人口、健康、出生率与死亡率，而不是靠君主的死亡威胁。见[米歇尔·福柯](eras/05-20th-century/michel-foucault.md)。
- **Boundary situation / 临界境遇：** 雅斯贝尔斯的术语，指那些无法被消除、被管理或被绕开来看的限度——死亡、痛苦、斗争、罪责、偶然——生存（Existenz）正是通过在它们面前搁浅才首次成为可能。见[卡尔·雅斯贝尔斯](eras/05-20th-century/karl-jaspers.md)。
- **Capabilities / 可行能力：** 森（及纳斯鲍姆）衡量优势的标准：人们实际上能够做和能够是的东西——他们真实的自由——而不是他们所持有的收入或资源。在"正义应当分配什么"的争论中，它被用来反驳罗尔斯。见[约翰·罗尔斯](eras/05-20th-century/john-rawls.md)。
- **Categorical imperative / 定言命令：** 康德的无条件道德律（与*假言命令*相对：后者是"如果你想要 X，就做 Y"）。
- **Category mistake / 范畴错误：** 赖尔的诊断：把某物当作属于某一逻辑范畴，而它实际上属于另一范畴——他以此指控笛卡尔"机器中的幽灵"式的心灵图景。见[吉尔伯特·赖尔](eras/05-20th-century/gilbert-ryle.md)。
- **Cogito / 我思：** 笛卡尔通过方法论怀疑所找到的不可怀疑的"我思／我在"。
- **Communicative action / 交往行动：** 哈贝马斯的术语，指以理由求得相互理解的互动，与以达到自己目的为目标的策略行为相对。一个社会的健康取决于前者不被后者挤走。见[法兰克福学派](eras/05-20th-century/frankfurt-school.md)。
- **Consequentialism / 后果主义：** 仅凭行为（或规则）的结果来评判它们的道德理论家族。功利主义是其最著名的成员；这个标签的范围比它更广。见[约翰·斯图亚特·穆勒](eras/04-19th-century/john-stuart-mill.md)。
- **Dasein / 此在：** 海德格尔的术语，指这样的人：对他而言，存在本身是一个问题；即"在那里存在"（being-there）。
- **Deontology / 义务论：** 以义务与规则为中心的道德理论：某些行为是必需的或被禁止的，与其结果如何无关。康德是其典范；与后果主义相对照。见[伊曼努尔·康德](eras/03-early-modern/immanuel-kant.md)。
- **Detachment / releasement (abegescheidenheit / gelâzenheit) / 超脱／泰然任之：** 埃克哈特的术语，指放下那执着于事物、执着于体验、乃至执着于自身圣洁的自我意志，使灵魂的根基足够空，好让圣言在其中诞生。这既不是轻视受造物，也不是逃离世界：他的典范是马大，她在世间劳作，却不执着于世间。见[伪狄奥尼修斯与埃克哈特大师](eras/02-medieval/pseudo-dionysius-and-eckhart.md)。
- **Dialectic / 辩证法：** （含义多样）苏格拉底式的问答；黑格尔通过内在矛盾的发展；马克思的唯物主义版本。**务必弄清作者用的是哪一种含义。**
- **Différance / 延异：** 德里达独创的术语（拼写中带一个 *a*），指差异与延宕的运作，语言的意义正是由此产生——意义从不完全在场，总是不断指向其他符号。见[雅克·德里达](eras/05-20th-century/jacques-derrida.md)。
- **Discipline (disciplinary power) / 规训（规训权力）：** 福柯的术语，指通过监视、时间表、考试与规范来训练身体的权力——学校、军营、医院、监狱——它生产出"驯顺的身体"，而不只是压制身体。见[米歇尔·福柯](eras/05-20th-century/michel-foucault.md)。
- **Double consciousness / 双重意识：** 杜波依斯的术语，指美国黑人分裂的自我：他被迫透过一个以轻蔑或怜悯旁观的世界的眼睛来看自己，因而感到一种"二重性"——既是美国人，又是黑人。造成它的那层帷幕也给予"第二视力"：对白人美国看得比它对自己看得更清楚。见[杜波依斯与法农](eras/05-20th-century/du-bois-and-fanon.md)。
- **Effective altruism / 有效利他主义：** 与辛格相关联的运动：运用证据与推理去做一个人所能做的最多的善——例如按可衡量的影响来比较慈善机构。见[彼得·辛格](eras/05-20th-century/peter-singer.md)。
- **Elenchus / 诘问法：** 苏格拉底对定义进行的驳斥式盘诘。
- **Empiricism / Rationalism / 经验论／唯理论：** 见 §3 开篇说明；这是关于知识来源的一个谱系，而非两个政党的成员资格。
- **Encompassing, the (das Umgreifende) / 大全：** 雅斯贝尔斯的名称，指这样一种视域：它包含主客分裂，自身却不是其中的一个对象——它就是存在本身，或者就是我们生活于其中的我们自己的生存。它可以被指明和澄清，但永远不能像认识一个事物那样被认识。见[卡尔·雅斯贝尔斯](eras/05-20th-century/karl-jaspers.md)。
- **Epochē / 悬置：** 悬置判断（皮浪式怀疑论者；胡塞尔借用这个词指现象学的悬搁——目的不同，请注意区别）。
- **Erring conscience / 错误的良心：** 经过诚实探究之后仍真诚地犯了错的良心；这个术语来自中世纪道德神学（阿奎那问"错误的良心是否有约束力"），培尔把它作为他为宽容辩护的枢纽。既然我们只能按我们看来为真的东西行事，而违背自己的良心行事才是真正的罪，他论证说，错误的良心与正确的良心享有同样的权利——因此"异端"与正统信徒一样有权不受干扰。见[培尔与伏尔泰](eras/03-early-modern/bayle-and-voltaire.md)。
- **Esoteric writing / 隐微写作：** 施特劳斯的术语，指在迫害或迫害威胁之下的一种写作方式，它有两层：一个普通读者与当局都能接受的显白教诲，和一个只有细心读者才能在字里行间恢复出来的隐微教诲。见[利奥·施特劳斯](eras/05-20th-century/leo-strauss.md)。
- **Eudaimonia / 幸福：** 在整个一生中兴旺／活得好；若简单地译作表示一种感觉的"幸福"（happiness）即是误译。
- **Expressivism / 表现主义：** 查尔斯·泰勒为赫尔德与哈曼的观点所取的名称：思想和意义并不是在我们表达之前就已在我们内部完成，而是在外在的表达中成形——对赫尔德来说首先是在语言中。由此推出对文化的多元论：每个民族都在自己的语言、诗歌和习俗中表达自身。见[哈曼与赫尔德](eras/03-early-modern/hamann-and-herder.md)。
- **Falsifiability / 可证伪性：** 波普尔的科学标准：一个理论只有当某种可能的观察能够构成对它的反驳时，它才是科学的。不可证伪的主张（他抨击的对象包括精神分析和庸俗马克思主义）能解释一切，因此什么也预言不了。见[卡尔·波普尔](eras/05-20th-century/karl-popper.md)。
- **Family resemblance / 家族相似：** 维特根斯坦用来替代本质的说法：一个范畴的成员（他的例子是游戏）可以由相互重叠的相似性联系在一起，而没有一个为全体所共有的单一特征。见[维特根斯坦（后期）](eras/05-20th-century/wittgenstein-late.md)。
- **Feeling of absolute dependence / 绝对依赖感：** 施莱尔马赫对宗教情感的定义：一种直接的自我意识，意识到自己的全部生存都来自并依赖于自身之外的一个"何所从来"（Whence）——它不是一种情绪，也不是从任何东西推论出来的。见[弗里德里希·施莱尔马赫](eras/04-19th-century/friedrich-schleiermacher.md)。
- **Forms (Platonic) / 理念（柏拉图的）：** 永恒而完善的原型，可感事物是它们的摹本，事物也正是凭借它们才可理解。
- **Gaze (the Look) / 凝视：** 被另一个意识当作对象来观看。对萨特而言，他者的凝视窃走了人的世界并固定了人的身份；波伏瓦将这一观念用在女性的处境上——生活在一种使她们成为对象的男性凝视之下。见[西蒙·德·波伏瓦](eras/05-20th-century/simone-de-beauvoir.md)。
- **Genealogy / 谱系学：** 尼采／福柯的方法：通过产生某种价值或范畴的偶然历史与利益来解释它。
- **General will / 公意：** 卢梭的说法，指公民整体以共同善为目标的意志——不同于私人意志的单纯总和（"众意"）。
- **Governmentality / 治理术：** 福柯的术语，指治理的整套机制——以管理人口的福祉与行为为目标的制度、程序、计算和心态。见[米歇尔·福柯](eras/05-20th-century/michel-foucault.md)。
- **Haecceity / 个别性：** 司各脱的"thisness"（个别性），即让一个个体成为这一个个体的东西。
- **Hermeneutics / 诠释学：** 最初是文本解释（尤其是圣经解释）的理论；伽达默尔将其推广为对一切理解的说明：理解总是从一种传统及其"偏见"内部出发来进行的。见[汉斯-格奥尔格·伽达默尔](eras/05-20th-century/hans-georg-gadamer.md)。
- **Hermeneutic circle / 诠释学循环：** 一切解释的结构：文本（或人生）的整体通过其部分得到理解，部分又通过整体得到理解，因此理解是通过在两者之间循环往复而前进的，而不是从零开始。这是文本解释的一条古老原则，由施莱尔马赫（继阿斯特之后）使之成为现代诠释学的核心，经海德格尔与伽达默尔而激进化。见[弗里德里希·施莱尔马赫](eras/04-19th-century/friedrich-schleiermacher.md)。
- **Idealism / 唯心主义：** （含义众多——须加区分！）贝克莱：只有心灵与观念存在。康德：我们只能认识被我们的认知所构造的事物（先验唯心主义 ≠ 贝克莱）。黑格尔：现实是精神／理性的自我发展。
- **Intentionality / 意向性：** 心灵的"关于性"（aboutness）——思想、知觉和欲望都指向对象这一事实。布伦塔诺复活了这个经院术语，把它当作心理现象的标志；胡塞尔使它成为现象学的中心主题。见[弗兰茨·布伦塔诺](eras/04-19th-century/franz-brentano.md)。
- **Internal / external questions / 内部问题／外部问题：** 卡尔纳普的区分，前提是我们采纳了一个语言框架（谈论某类事物——例如数——的一套词语和规则）：内部问题在框架之内提出和回答（"10 与 20 之间有素数吗？"），外部问题则追问这整个实体系统是否独立于任何框架而真实（"数真的存在吗？"）。按字面理解，外部问题没有认知内容；有意义的是是否采纳该框架这一实践问题。见[鲁道夫·卡尔纳普](eras/05-20th-century/rudolf-carnap.md)。
- **Internal relations (doctrine of) / 内在关系（学说）：** 这样一种观点：一个事物所具有的每一种关系都属于它的本性，因此没有任何东西能脱离其他一切而是其所是；与*外在关系*相对，后者不改变其关系项。罗素把它当作观念论者的学说来抨击，但布拉德雷本人认为，没有任何关系——无论内在的还是外在的——是终极实在的。见[T. H. 格林与 F. H. 布拉德雷](eras/04-19th-century/british-idealists.md)。
- **Intuitive cognition / 直觉认知：** 对司各脱和奥卡姆而言，指直接认识到一个事物存在并在场，与*抽象认识*相对：后者考察一个事物，但不确定它是否存在。这个小小的区分驱动着他们的整个认识论。见[约翰·邓斯·司各脱](eras/02-medieval/john-duns-scotus.md)。
- **Invisible hand / 看不见的手：** 斯密的比喻：自利的行为如何能无意地产生公共利益（在《国富论》中，是一个商人为了自身安全而宁愿支持本国产业而非外国产业）——他很少使用这个短语，后来的读者把它夸大了。见[亚当·斯密](eras/03-early-modern/adam-smith.md)。
- **Ius gentium / 万国法：** 拉丁语，意为"诸民族之法"。对苏亚雷斯而言，它是人法（而非自然法），为许多民族（虽非所有民族）所共有，依据的是共同的习俗而非某一个立法者，因此原则上可以改变——例如，它规范着自然法所允许、却并不亲自确立的财产与奴隶制。它不是现代意义上的国际法。见[苏亚雷斯与格劳秀斯](eras/03-early-modern/suarez-and-grotius.md)。
- **Language-game / 语言游戏：** 维特根斯坦的语言图景：语言是编织在生活形式之中的、受规则支配的活动的家族——提问、开玩笑、下命令、道谢——其意义由用法赋予，而不是由命名赋予。见[维特根斯坦（后期）](eras/05-20th-century/wittgenstein-late.md)。
- **Legal positivism / 法律实证主义：** 这样一种观点：法律*是*什么取决于社会事实——什么已被制定、判决或依习惯被接受——而不取决于它在道德上是否良善，因此"法律是什么？"与"它是不是好法律，我应当服从它吗？"是分开的问题。哈特的版本承自边沁与奥斯丁；与富勒所说的法律的"内在道德"相对。见[H. L. A. 哈特](eras/05-20th-century/h-l-a-hart.md)。
- **Lifeworld (Lebenswelt) / 生活世界：** 胡塞尔的术语，指日常经验的前理论世界，科学以它为前提并从中抽象；哈贝马斯接过它，指他所谓被市场与官僚体制殖民化的共享意义领域。见[法兰克福学派](eras/05-20th-century/frankfurt-school.md)。
- **Logos / 逻各斯：** 希腊词，含义涵盖言语、理性、说明、宇宙秩序——赫拉克利特与斯多葛学派利用了它所有的含义。
- **Modal realism / 模态实在论：** 大卫·刘易斯的观点：其他可能世界与我们的世界同样真实、同样具体，每一个在时空上都与其他世界隔绝；"现实的"一词的作用就像"这里"，挑出我们所在的那个世界。对我来说什么是可能的，取决于我的*对应体*，即其他世界中与我极为相似的人。见[塞拉斯、戴维森、普特南与刘易斯](eras/05-20th-century/analytic-philosophy-after-quine.md)。
- **Monad / 单子：** 莱布尼茨的说法：简单的、能知觉的、没有窗户的实体。
- **Moral sense / 道德感：** 哈奇森的名称，指一种天生的能力：无论在自己身上还是在他人身上，它都因仁爱的动机而愉悦、因恶意的动机而不快，并且是直接起作用的，先于任何关于自身利益的推理。它以洛克的反省观念为模型，并非字面意义上的感官；沙夫茨伯里的"是非感"在先，而巴特勒更愿意谈论良心。见[沙夫茨伯里、哈奇森与巴特勒](eras/03-early-modern/moral-sense-school.md)。
- **Myth of the Given / 所予神话：** 塞拉斯的名称，指这样一种经验论观念：知识建立在某些被直接认知的项目（如感觉印象）之上，它们无需推论，也无需先有其他知识。他论证说，没有什么能同时胜任这两项工作：要充当理由，它就必须是类似断言的，那它就不再是赤裸的、不含概念的了。称某物为知识，就是把它置于"理由的逻辑空间"之中。见[塞拉斯、戴维森、普特南与刘易斯](eras/05-20th-century/analytic-philosophy-after-quine.md)。
- **Natural law / 自然法：** 一种植根于自然、而非任何国家之制定的道德法，对每一个民族都有约束力，无论其宗教为何。苏亚雷斯认为，它的内容来自自然，但它作为法的效力来自上帝的意志；格劳秀斯把它定义为正当理性的命令，并说即使"假如"没有上帝它也依然成立——他称这个假设是邪恶的。见[苏亚雷斯与格劳秀斯](eras/03-early-modern/suarez-and-grotius.md)。
- **Necessary Existent / 必然存在者：** 伊本·西那／阿奎那的上帝：其存在不由他者引起的存在者。
- **Narrative identity / 叙事同一性：** 利科对自我状态的说明：一个生命通过被编织成情节而成为一个自我——被讲述为一个故事，它在 *idem*（品格，保持不变的东西）与 *ipse*（自我恒定，如信守承诺）之间起中介作用。见[保罗·利科](eras/05-20th-century/paul-ricoeur.md)。
- **Nominalism / Realism (universals) / 唯名论／实在论（共相问题）：** 共相只是名称／概念／共相是真实的。*不是*这些词在现代政治中的含义。
- **Non-identity problem / 非同一性问题：** 帕菲特的难题：决定了*哪些*人将会存在的选择（如长期政策）似乎没有冤枉任何人，因为由此产生的人本来不可能以其他方式存在——但这些选择仍可能显得是错的。见[德里克·帕菲特](eras/05-20th-century/derek-parfit.md)。
- **Normal science / 常规科学：** 库恩的术语，指在一个被接受的范式之内进行的研究——即阐发范式而非检验其基础的解谜活动。见[托马斯·库恩](eras/05-20th-century/thomas-kuhn.md)。
- **Noumenon / Phenomenon / 本体／现象：** 康德：物自身（不可知）／物在我们的认知形式之下显现的样子。
- **Nous / 努斯：** 希腊语，指理智／心灵——在亚里士多德那里，它是直接把握第一原理的官能，也是《论灵魂》III.5 中"主动理智"，其与身体的分离问题被争论了几个世纪。见[亚里士多德](eras/01-ancient/aristotle.md)。
- **Occasionalism / 偶因论：** 这样一种观点：上帝是唯一真正的原因，受造物只是上帝借以行动的机缘：一个台球撞击另一个时，是上帝推动了第二个球。马勒伯朗士把它建成一个完整的体系；安萨里通常被读作偶因论者，尽管学者对此有争议。休谟保留了否定性的论证（我们从未知觉到必然联系），而去掉了上帝。见[尼古拉·马勒伯朗士](eras/03-early-modern/nicolas-malebranche.md)。
- **Ontological argument / 本体论论证：** 安瑟尔谟从上帝的概念出发推论上帝存在的先天论证。
- **Open question (argument) / 开放问题（论证）：** 摩尔用来反对给"善"下定义的检验：对任何提出的定义（善＝快乐、善＝我们所欲求的东西），"具有那种性质的东西是否善"仍然是一个开放的、实质性的问题——因此"善"并不等同于任何自然性质。这是他反对"自然主义谬误"的论据。见[G. E. 摩尔](eras/05-20th-century/g-e-moore.md)。
- **Original position / 原初状态：** 罗尔斯设想的、用来选择正义原则的假定立场：各方在无知之幕后面进行选择，不知道自己的才能、阶级或善观念。见[约翰·罗尔斯](eras/05-20th-century/john-rawls.md)。
- **Other, the (autrui) / 他者：** 作为不可还原的他者的另一个人。对列维纳斯而言，他者的面容发出"你不可杀人"的命令，并使伦理学先于一切理论；这个术语在萨特和波伏瓦那里也有不同的含义。见[伊曼努尔·列维纳斯](eras/05-20th-century/emmanuel-levinas.md)。
- **Paradigm / 范式：** 库恩的术语，指界定一个科学共同体工作的理论、方法、标准和典范问题之总体；*范式转换*是（罕见且有争议的）在危机之后一个范式被另一个范式取代。见[托马斯·库恩](eras/05-20th-century/thomas-kuhn.md)。
- **Performativity / 操演性：** 巴特勒对性别的说明：性别是由重复的行为——走路、穿着、说话和欲望的方式——构成的，而不是由一个内在核心表达出来的。这个术语来自奥斯汀那些做其所说之事的句子（"我承诺"）。它不是每天早上挑选的一套戏服，而是对规范被迫的、重复的引用，正是这种引用形成了那个后来可能抵抗规范的自我。见[伊利格瑞、克里斯蒂娃与巴特勒](eras/05-20th-century/feminist-philosophy-after-beauvoir.md)。
- **Personal identity / 人格同一性：** 使一个人在一个时间的那个人与在另一个时间的同一个人成为同一个人的东西。洛克将其系于意识的连续性（记忆）；帕菲特则认为，真正要紧的那种关系可以有程度之分，而且同一性"不是要紧的东西"。见[约翰·洛克](eras/03-early-modern/john-locke.md)。
- **Phenomenology / 现象学：** 胡塞尔描述意识经验的方法；后来发展为整个大陆哲学运动。
- **Physis / Nomos / 自然／习俗：** 自然／约定或法律。智者派与其批评者争论：正义、道德与诸神是凭自然（physis）存在，还是仅凭习俗（nomos）存在——这是第一场伟大的自然与文化之争。见[普罗塔哥拉与智者派](eras/01-ancient/protagoras-and-the-sophists.md)。
- **Positive freedom / 积极自由：** T. H. 格林对自由的说明：自由是做值得做之事的真实能力，由社会为其全体成员保障，而不只是没有限制。它为改革立法提供了正当理由，并给了新自由主义以哲学基础；以赛亚·伯林后来警告说，谈论"真正的"自由可能为强制开绿灯。见[T. H. 格林与 F. H. 布拉德雷](eras/04-19th-century/british-idealists.md)。
- **Praxis / 实践：** 行动／实践——在马克思那里，指人借以造就自身及其历史的感性的、改变世界的活动；哲学不应只解释世界，还应参与改变世界。见[卡尔·马克思](eras/04-19th-century/karl-marx.md)。
- **Presentational symbol / 呈现性符号：** 朗格的术语，指这样一种象征——一幅图像、一个仪式、一部音乐作品——其意义在于整体的同时呈现的形式，而不像推论性语言中的词那样在于可逐一翻译的部分。艺术是她的主要例子：艺术表达了情感的形式。见[苏珊·朗格](eras/05-20th-century/susanne-langer.md)。
- **Principle of charity / 宽厚原则：** 戴维森的彻底解释规则：假定说话者的信念按我们的标准大多是真的、一致的——这是打破"信念与意义须一并推出"这一循环的唯一途径。它不是礼貌，而是把那些声音当作语言来对待的条件；分歧只有在大量一致的背景下才有意义。见[塞拉斯、戴维森、普特南与刘易斯](eras/05-20th-century/analytic-philosophy-after-quine.md)。
- **Principle of tolerance / 宽容原则：** 卡尔纳普的原则：逻辑与数学中相互竞争的立场，并不是关于同一个实在的真或假的主张，而是关于语言的提议，按它们服务于某一目的的好坏来评判。任何人都可以构造一种语言；唯一的要求是清楚地陈述其规则。见[鲁道夫·卡尔纳普](eras/05-20th-century/rudolf-carnap.md)。
- **Private language argument / 私人语言论证：** 维特根斯坦的论证：一门原则上只有一个人能理解的语言是不可能的：没有正确用法的公共标准，"看似正确"与"确实正确"就会彼此坍塌。见[维特根斯坦（后期）](eras/05-20th-century/wittgenstein-late.md)。
- **Procession and return / 发出与回归：** 普罗克洛的法则：每一个结果都*驻留*于其原因之中，从原因中*发出*，又通过渴慕与模仿其来源而*回归*（返回）于它——就像一束光线始终与太阳相连，从太阳射出，又指回太阳。原因给出而自身不减损，这一流出与回归把存在的每一个层级连接起来。见[波菲利、扬布里柯、普罗克洛与希帕提娅](eras/01-ancient/late-neoplatonists.md)。
- **Public sphere / 公共领域：** 私人形成公共舆论而不受国家控制的场所——沙龙、报刊、社团。哈贝马斯追溯了它的资产阶级兴起及其被大众传媒与商业扭曲的过程。见[法兰克福学派](eras/05-20th-century/frankfurt-school.md)。
- **Recognition (Anerkennung) / 承认：** 被另一个自我意识的行动者承认为一个自我意识的行动者。黑格尔的主奴辩证法认为，自我意识只能被来自一个平等的他者的承认所满足——这一主题从费希特一直延续到现代承认理论。见[G. W. F. 黑格尔](eras/04-19th-century/g-w-f-hegel.md)。
- **Re-enactment / 重演：** 柯林伍德对历史学家如何认识过去的说明：在自己的心中重新思考过去的思想，就像人们追随柏拉图的论证，或按凯撒所见的样子推演他的处境。"思想"指可以被重新思考的推理，而不是感受；重演是批判性的，在重新思考时作出判断；它不是心灵感应。见[狄尔泰与柯林伍德](eras/04-19th-century/dilthey-and-collingwood.md)。
- **Reflective equilibrium / 反思平衡：** 罗尔斯的论证方法：来回调整原则与深思熟虑的判断，直至它们融贯一致，且事先不固定任何一方。如今它是伦理学与政治哲学中的一种标准方法。见[约翰·罗尔斯](eras/05-20th-century/john-rawls.md)。
- **Reification (Verdinglichung) / 物化：** 卢卡奇的术语，被法兰克福学派采用：把人的关系与过程当作仿佛是物——固定的、自然的、不受任何人控制的。见[法兰克福学派](eras/05-20th-century/frankfurt-school.md)。
- **Rhizome / 根茎：** 德勒兹与加塔利的思想意象：像马唐草或姜的根茎一样，它没有中心，任何一点都可以与任何其他一点相连。与*树*相对：树有根、干和枝，是一个只有单一起源的等级体系。《千高原》本身就意在成为一个根茎。见[吉尔·德勒兹](eras/05-20th-century/gilles-deleuze.md)。
- **Rule of recognition / 承认规则：** 哈特的次级规则，它给出哪些规则属于一个法律体系的标准（在英国，大致是女王在议会中所制定的一切）。它的有效并不是因为某条更高的规则如此规定；它作为一个社会事实存在，即官员在决定什么算作法律时实际使用的那条规则。与凯尔森那必须被预设的"基础规范"相对。见[H. L. A. 哈特](eras/05-20th-century/h-l-a-hart.md)。
- **Semantic externalism / 语义外在论：** 普特南以孪生地球案例论证的观点：头脑中的东西并不决定词语指称什么：两个分子对分子完全相同的孪生者说"水"时，如果他们的世界不同，他们指称的就是不同的物质（H₂O 与 XYZ）。指称取决于世界的深层本性，以及与专家之间的语言分工。见[塞拉斯、戴维森、普特南与刘易斯](eras/05-20th-century/analytic-philosophy-after-quine.md)。
- **Semiotic, the / 符号态：** 克里斯蒂娃的名称，指言语的节奏、音调和声音模式，它们负载着身体的驱力，先于婴儿对词语的把握，并与母亲的身体联系在一起。与*象征态*相对：作为语法、逻辑和指称的语言，与社会法则相连。每一句话语都混合着两者，而两者都属于每一个说话者。见[伊利格瑞、克里斯蒂娃与巴特勒](eras/05-20th-century/feminist-philosophy-after-beauvoir.md)。
- **Social contract / 社会契约：** 通过自由个体之间（通常是假定的）协定来解释政治权威的装置——霍布斯（安全）、洛克（权利与同意）和卢梭（公意）对它的使用大相径庭。见[托马斯·霍布斯](eras/03-early-modern/thomas-hobbes.md)。
- **Substance / attribute / mode / 实体／属性／样态：** 斯宾诺莎的三层本体论：实体是自存的东西（上帝即自然，独一无二）；属性是理智所知觉到的实体的本质（思想和广延是我们所知道的两个属性）；样态是实体的具体变状——每一个有限的事物与思想。见[巴鲁赫·斯宾诺莎](eras/03-early-modern/baruch-spinoza.md)。
- **Superstructure (base and) / 上层建筑（与经济基础）：** 马克思的建筑学比喻：经济基础（生产力与生产关系）制约着建立其上的法律、政治与意识形态的上层建筑。"制约"到底有多强，仍是一个持续的学术争论。见[卡尔·马克思](eras/04-19th-century/karl-marx.md)。
- **Supposition / 指代：** 中世纪关于语词在命题中如何指代事物的理论（由奥卡姆赋予经典形式）——中世纪逻辑学家用来辨明一句话究竟使我们承诺了什么的工具。见[奥卡姆的威廉](eras/02-medieval/william-of-ockham.md)。
- **Synthetic a priori / 先天综合：** 康德的关键范畴：真正扩展知识（综合的）却又能独立于经验而知（先天的）判断——他的例子包括算术和因果性原理。它们是否可能、如何可能，是《纯粹理性批判》的中心问题。见[伊曼努尔·康德](eras/03-early-modern/immanuel-kant.md)。
- **Tabula rasa / 白板：** "白板"，是后人对洛克那个意象的简称：心灵如一张"白纸"，由经验来充实；他否认的是天赋观念，而不是天赋能力。见[约翰·洛克](eras/03-early-modern/john-locke.md)。
- **Telos / 目的：** 终点／目的；亚里士多德部分地以事物的目的（目的因）来解释事物。
- **Theurgy / 通神术：** "神工"：仪式行为、祷告、神圣的名字与器物，扬布里柯认为，诸神本身正是借此把灵魂提升到他们那里。他反对普罗提诺，教导说灵魂完全降入身体，无法靠自己的思考回归，因此与诸神的合一来自仪式，而非理智的努力。他坚持说，这些仪式并不强迫诸神。见[波菲利、扬布里柯、普罗克洛与希帕提娅](eras/01-ancient/late-neoplatonists.md)。
- **Transcendental / 先验的：** 康德的用法：关乎经验／知识的*可能性条件*，而不是关乎一个"彼岸"的世界（避免与日常用语中的"超验的"（transcendent）混淆）。
- **Univocity / 单义性：** 司各脱的主张："存在"在*同一种*意义上既可说上帝也可说受造物（与阿奎那的类比说相对）：没有一个共享的存在概念，神学根本无法证明关于上帝的任何东西。见[约翰·邓斯·司各脱](eras/02-medieval/john-duns-scotus.md)。
- **Utilitarianism / 功利主义：** 正当行为使总体的福祉／幸福最大化（边沁、穆勒、辛格，各有不同版本）。
- **Veil of ignorance / 无知之幕：** 罗尔斯的装置：在不知道自身社会地位的情况下选择正义原则。
- **Verification principle / 证实原则：** 维也纳学派的意义标准：一个（非重言式的）陈述只有当某种可能的经验能够证实它或有助于确立其为真时，才有意义。它著名地难以证实自身——这是其辩护者必须回答的问题。见[维也纳学派／逻辑实证主义](eras/05-20th-century/vienna-circle-logical-positivism.md)。
- **Verstehen (understanding) / 理解：** 狄尔泰的术语，指人文科学如何从内部把握人类行动及其产物的意义，因为探究者与被研究者是同一种存在者；与*说明*（Erklären）相对，即自然科学从外部把事件归入因果律之下。它不只是移情：对后期狄尔泰来说，它通过公共的表达和语境来进行。见[狄尔泰与柯林伍德](eras/04-19th-century/dilthey-and-collingwood.md)。
- **Virtual, the / 潜在：** 德勒兹取自柏格森的术语，指真实但非现实的东西：一个由微分关系和阈值（"奇异点"）构成的场，系统在这些点上改变其行为。事物通过*现实化*而成为现实的，而现实化从不类似于它所由来的潜在；与*可能*相对，可能被设想为现实的一个现成摹本。见[吉尔·德勒兹](eras/05-20th-century/gilles-deleuze.md)。
- **Virtue (aretē) / 德性：** 品格／功能的卓越，而不只是遵守规则；是柏拉图、亚里士多德、斯多葛学派、阿奎那的核心概念。
- **Vision in God / 在神之中看见：** 马勒伯朗士的观点：我们通过存在于上帝之中的观念来知觉物体——上帝包含着他所造一切事物的原型——因为观念的其他一切可能来源都站不住脚。我们看见的不是上帝的本质，而只是上帝之中表象受造物的东西。见[尼古拉·马勒伯朗士](eras/03-early-modern/nicolas-malebranche.md)。
- **Will to power / 权力意志：** 尼采为他认为潜藏于生命与价值创造之下的驱动力所取的名字——并不只是政治统治，尽管这一学说究竟是心理学的、生物学的还是形而上学的，仍有争论。见[弗里德里希·尼采](eras/04-19th-century/friedrich-nietzsche.md)。
