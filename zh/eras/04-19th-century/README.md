# 19世纪哲学（1801 – 1900）

**简体中文** | [English](../../../eras/04-19th-century/README.md)

界限说明：边沁（生于1748年）与黑格尔（生于1770年）是起点；皮尔士（卒于1914年）、詹姆斯（卒于1910年）、尼采（卒于1900年，1889年后不再有产出）为终点——他们的奠基性工作属于19世纪，尽管其影响属于20世纪。

## 时代概览
康德之后——以及黑格尔之后的哲学。康德限定了理性所能认识的范围；这里的每一位都在完成、对抗或取代那一安排。
驱动因素：（1）黑格尔体系的兴起与崩解；1831年后学派分裂为右派黑格尔派与青年/左派黑格尔派（费尔巴哈、施蒂纳、青年马克思）；整个世纪所做的，就是抽取其中一块（历史、异化、承认、辩证法），抛弃体系本身。（2）历史成为一个哲学范畴（黑格尔、马克思；尼采的"谱系学"）。（3）工业化/资本主义/革命：1848年、工厂劳动、斯密/李嘉图 → 穆勒与马克思成为工业—商业社会的理论家。（4）自然科学的声望：达尔文《物种起源》（1859年）、热力学、实验心理学 → 或是变得科学化（穆勒、皮尔士、詹姆斯），或是捍卫科学无法占据的空间（克尔凯郭尔、叔本华、尼采）。（5）决定下一世纪的分裂：英美的经验论/逻辑路线（穆勒→皮尔士/詹姆斯→罗素/分析哲学）与德国—欧洲的存在/历史/批判路线（克尔凯郭尔、马克思、尼采→存在主义、马克思主义、批判理论、后结构主义）。
反复出现的问题：如果继承的宗教、永恒的理性与传统的道德不能再被简单地假定，那么什么能为知识与生活奠基——历史、效用、意志、物质生产、个体的选择，还是实际的后果？

## 本时代内的学习顺序
1. 先读穆勒（+边沁专栏）：《论自由》、《功利主义》第2章——清晰，无先修要求，自由主义—经验论的一极。
2. 黑格尔要在指导下读：先读二手文献，再读《精神现象学》序言 + 主奴关系部分。理解马克思/克尔凯郭尔/费尔巴哈出发点所必需；无人指导先读黑格尔 = 最常见的放弃原因。
3. 费尔巴哈选段 → 马克思：《共产党宣言》 + 1859年序言 + 1844年的异化。
4. 叔本华：先读随笔，再读《作为意志和表象的世界》选段——置于黑格尔之后（有意的反黑格尔），尼采之前（尼采以门徒身份起步）。
5. 克尔凯郭尔：《恐惧与颤栗》——置于黑格尔之后（其靶子），与叔本华并列，作为另一种反体系的内向转向。
6. 尼采：《论道德的谱系》第一篇论文，再读《快乐的科学》选段——几乎与上述所有人论战。
7. 地图级，黑格尔之后任何时候：格林与布拉德雷（英国观念论，摩尔与罗素的靶子）以及狄尔泰（理解与说明之分，通往伽达默尔的桥梁）。
8. 皮尔士 → 詹姆斯置于最后（出于教学法，而非重要性）：皮尔士的两篇论文，然后詹姆斯《实用主义》第2、6讲。实用主义作为对这一时代唯心主义/经验论僵局的回应。
施蒂纳作为可选附论，置于第3与第4之间。

## 需保留的年代细节
叔本华《作为意志和表象的世界》：1818年（12月完成/出版）与1819年（书名页）。穆勒《功利主义》：1861年连载 / 1863年成书。黑格尔《逻辑学》：1812–16年（某些SEP版本作1812–18年）。施蒂纳《唯一者及其所有物》：1844年出版 / 1845年书名页。马克思《1844年经济学哲学手稿》与《德意志意识形态》生前未刊，20世纪才首次出版（《手稿》为1932年）。
