# 中世纪哲学（约400年—约1400年）

**简体中文** | [English](../../../eras/02-medieval/README.md)

范围：按惯例从奥古斯丁（Augustine，354—430年）到奥卡姆（Ockham，卒于1347年），其中爱留根纳（Eriugena）与希尔德加德（Hildegard）恢复到其年代位置，库萨的尼古拉（Nicholas of Cusa，1401—1464年）作为15世纪的尾声收入——严格说已越过本时代约1400年的界限，但他的“有学识的无知”收束了中世纪的故事，并通向文艺复兴。奥古斯丁严格说属于古代晚期／教父时期，但中世纪哲学按惯例从他讲起（斯坦福哲学百科全书〔SEP〕的惯例），因为其后所有人都在与他争论。伊本·西那（Avicenna）、伊本·鲁世德（Averroes）、迈蒙尼德（Maimonides）并非拉丁基督徒，也不用拉丁文写作——收入他们，是因为拉丁欧洲在很大程度上是**经由**他们接受亚里士多德（Aristotle）的。

## 时代概览

一句话概括：近一千年间，三种宗教中最聪明的一批人都在追问：理性靠自身能证明什么，什么必须凭信仰／启示接受，二者看似冲突时又会怎样？——他们所用的工具是希腊逻辑，主要是亚里士多德的逻辑，先是片段，（12—13世纪）继而洪流般涌入。

要素：两座并不显然一致的权威文库（圣经／教父；《托拉》；《古兰经》——以及希腊哲学，先是经奥古斯丁／新柏拉图主义传入的柏拉图〔Plato〕，后来是完整的亚里士多德）。制度：修道院／主教座堂学校（至约1200年），其后是大学（博洛尼亚、巴黎、牛津）与托钵修会——多明我会（阿奎那〔Aquinas〕、阿尔伯特〔Albert〕）对法方济各会（司各脱〔Scotus〕、奥卡姆、波纳文图拉〔Bonaventure〕）；许多分歧都对应这一分裂。

传承（关键，常被略过）：希腊哲学在阿拉伯世界（巴格达、波斯、安达卢斯）得到保存、发展与注释。12至13世纪托莱多与西西里的译者（克雷莫纳的杰拉德〔Gerard of Cremona〕、贡迪萨尔维〔Gundisalvi〕、迈克尔·斯科特〔Michael Scot〕）把亚里士多德**以及**伊本·西那、伊本·鲁世德、法拉比（al-Fārābī）、安萨里（al-Ghazālī）译成拉丁文；SEP强调，（而非个人接触）正是这些译本构成主要渠道，并“改变了13世纪的大学课程表”。迈蒙尼德的《迷途指津》（Guide）以犹太—阿拉伯语写成，经13世纪的拉丁译本到达拉丁读者手中。没有阿拉伯／希伯来中介，拉丁中世纪便无从理解。

信仰／理性谱系（不是一场战争）：
- 奥古斯丁：理性侍奉信仰，并被信仰医治——“为了理解而相信”（Believe in order to understand）
- 爱留根纳：真正的权威与正确的理性永不冲突，因为二者出自同一神圣智慧——而理性终结于否定神学，即认识到上帝超越存在本身
- 安瑟尔谟（Anselm）：信仰寻求对它已持有的东西的理性证明——信仰寻求理解（fides quaerens intellectum）
- 阿伯拉尔（Abelard）：把诸权威并置，让逻辑来裁断——《是与否》（Sic et Non）
- 希尔德加德：通过异象获得知识——启示被直接经验到，再由教会授权；理性的角色是接受、检验并阐明“活光”所显示的东西
- 伊本·西那：理性／论证能独立地达到关于上帝／灵魂的确然真理——必然存在者（Necessary Existent）
- 伊本·鲁世德、迈蒙尼德：哲学与启示终究不能矛盾；冲突是解释问题——一个真理，不同路径／不同受众
- 阿奎那：两个相异而和谐的领域；理性证明一些事（上帝存在），启示给出另一些（三位一体）——“恩典并不毁坏自然，而是成全自然”（Grace does not destroy nature, but perfects it）
- 司各脱：理性需要一个关于“存在”的共享概念，才能对上帝有所言说——存在的单义性（univocity）
- 奥卡姆：理性的疆域收缩；许多教义只能凭信仰；逻辑不应凭空造出实体——唯名论（nominalism）加简约原则
- 库萨：有学识的无知——理性精确地量出自身的限度，并恰恰通过认识到自己无法领会上帝而认识上帝；对立面在无限中重合

真实的紧张确实存在（1270年与1277年的谴责，巴黎主教，针对激进的亚里士多德主义／阿威罗伊主义论题；1277年共219条论题），但默认的工程是调和，而非开战。

共相问题（本时代最长的争论；波爱修斯〔Boethius〕经波菲利〔Porphyry〕提出）：
- 极端实在论：共相作为分离的实在之物存在（尚波的威廉〔William of Champeaux〕，阿伯拉尔的老师，被阿伯拉尔驳倒）
- 温和实在论：共相以形式／本性的方式存在于个别事物之中，由心灵抽象出来（阿奎那；司各脱独具一格的“共同本性”）
- 概念论：共相是概念——以真实的相似性为根据，在心灵／语言之外无存在（阿伯拉尔——这一标签是后世加的）
- 唯名论：只有个体存在；共相是代表众多事物的符号（奥卡姆，在罗斯塞林〔Roscelin〕的基础上发展）

线索：波爱修斯提出框架；阿伯拉尔使之炽热；阿奎那／司各脱给出精细程度递增的实在论回答；奥卡姆将其消解。这是贯穿本时代的最佳单线。

经院方法：讲读（lectio，对权威文本——亚里士多德、圣经、波爱修斯、彼得·伦巴德〔Peter Lombard〕的《箴言集》〔Sentences〕——的细密注释）；问题（quaestio，从相互冲突的权威中提炼出的孤立争议问题）；辩论（disputatio，正式论辩）；书面文章体式（阿奎那）：异议（Objections）→ 反之（Sed contra）→ 我的回答是（Respondeo）→ 逐一答复异议。教会初学者认出这副骨架，《神学大全》（Summa）便不再像一面墙。许多最好的工作是在注释内部完成的——注释是原创思想的载体，而非摘要。

其他反复出现的问题：上帝存在的证明（安瑟尔谟、伊本·西那、阿奎那、司各脱——四种策略）；预知与自由（奥古斯丁、波爱修斯、阿奎那、司各脱、奥卡姆）；世界的永恒与受造（伊本·西那主张流溢／永恒；迈蒙尼德认为理性无法判定；阿奎那认为在时间中受造靠信仰，永恒不可驳倒）；灵魂／理智（伊本·西那的飞人；伊本·鲁世德的单一理智与阿奎那的驳斥）；认知——我们如何知道单称事物存在（司各脱的直觉认知与抽象认知之分；奥卡姆以直觉认知为知识的基础，这是继共相问题之外第二条贯穿司各脱→奥卡姆的线索）；恶／天意；法律／伦理（阿奎那的自然法；阿伯拉尔的意向伦理）。

## 学习顺序

推荐“接受顺序”（观念在拉丁欧洲实际到达／碰撞的顺序）：
1. 奥古斯丁——设定一切问题；原典可读。
2. 波爱修斯——桥梁；共相＋预知。
3. 爱留根纳——加洛林时期的体系建造者；希腊否定神学进入拉丁西方（在波爱修斯之后读，他把波爱修斯的柏拉图主义推向极端）。先读伪狄奥尼修斯短小的《神秘神学》：它正是爱留根纳所翻译的那个源头。
4. 安瑟尔谟——第一个真正的论证；小篇幅文本＋高尼罗（Gaunilo）。
5. 阿伯拉尔——方法的时代；共相第二回合；意向伦理。
6. 希尔德加德——异象式的对照面：通过经验与权威获得知识，在修院中写作，而学校在争论。
7. 伊本·西那——年代上与安瑟尔谟重叠，但欧洲在12世纪才遇见他；本质／存在＋必然存在者＋飞人现在读，因为阿奎那以它们为前提。
8. 先读安萨里，再并行读伊本·鲁世德与迈蒙尼德——《哲学家的矛盾》正是伊本·鲁世德所回应的那场攻击；这些是阿奎那指名与之争论的、经亚里士多德中介的声音；有短小的条目可读（《决定性的论述》；《迷途指津》第一部分选读）。
9. 阿奎那——综合在此落地（五路证明、自然法、反阿威罗伊主义）。
10. 司各脱——精微的批判（单义性、个别性〔haecceity〕、形式区分、直觉认知）。
11. 奥卡姆——消解；唯名论／简约原则是这场始于波爱修斯的共相博弈的最后一步棋，以及针对司各脱的直觉认知论。
12. 在地图层面读克里斯蒂娜·德·皮桑（《妇女城》第一卷）与埃克哈特大师，然后读库萨的尼古拉——尾声与枢纽：有学识的无知把本时代的信仰／理性之争收拢为一套关于限度的学说，并指向文艺复兴。

备选的严格年代顺序：奥古斯丁 → 波爱修斯 → 爱留根纳 → 伊本·西那 → 安瑟尔谟 → 阿伯拉尔 → 希尔德加德 → 伊本·鲁世德 → 迈蒙尼德 → 阿奎那 → 司各脱 → 奥卡姆 → 库萨（准确，但教学上更难）。

考试复习：把十三人全部放回共相表＋信仰／理性谱系之上。

## 常见过度简化（总论）

- “黑暗时代：信仰压制理性一千年”——**错误**：这个时代发明了大学、正式论辩和逻辑的大部分内容；思想家们无休止地争论，有时反对权威所偏好的答案，并为此付出代价（阿伯拉尔两度受谴责，奥卡姆被绝罚，219条论题于1277年在巴黎受谴责）。工程是调和，不是压制。
- 信仰与理性是谱系，不是两军对垒（阿奎那同时限制理性主义与信仰主义）。
- 实在论者大多是**温和**实在论（本性在事物之中），而不是漂浮的柏拉图理念（Forms）。
- 伊本·西那／伊本·鲁世德／迈蒙尼德是原创的体系建造者，不是单纯的传递者；他们在伊斯兰／犹太世界以阿拉伯语／犹太—阿拉伯语写作——收入他们需要传承叙事，而非把他们默默吸收为“欧洲人”。
- 阿伯拉尔“是概念论者，到此为止”是后世标签，指他用语言学语汇表述、且不断修订的立场。
- 伊本·西那的《治愈之书》（Book of Healing）≠ 医学书（那是《医典》〔Canon of Medicine〕）；治愈，指的是灵魂脱离无知的治愈。
