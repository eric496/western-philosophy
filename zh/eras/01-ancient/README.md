# 古代哲学（约公元前600年 – 约公元270年）
**简体中文** | [English](../../../eras/01-ancient/README.md)

范围：约公元前624年（泰勒斯）至公元270年（普罗提诺）。亚里士多德之前的年代均为约数。前苏格拉底哲学家仅有残篇与述行（testimonia，即二手转述）传世。

## 时代概览
依次展开的三场对话：
1. 前苏格拉底哲学家（公元前6–5世纪）：“万物由什么构成，变化如何发生？”——寻找一个自然的第一原理（本原，archē），以取代神话。赫拉克利特（变化）对巴门尼德（变化在逻辑上不可能）；原子论回应巴门尼德，同时保全变化。
2. 古典雅典转向（公元前5–4世纪）：“我们应当如何生活，我们的词语意味着什么？”——苏格拉底把哲学转向德性、知识与美好生活；柏拉图建构形而上学与政治体系；亚里士多德将逻辑、生物学、伦理学、政治学、形而上学系统化，把知识奠基于此世。
3. 希腊化／罗马学派（约公元前323年–公元3世纪）：“在一个我无法掌控的世界里，我如何能不受扰动？”——相互竞争的生活方式——伊壁鸠鲁派、斯多亚派、怀疑派、犬儒派——核心目标是心灵安宁（ataraxia，不受扰动）。逻辑与物理学服务于伦理学。以普罗提诺收尾：他把柏拉图熔铸为宗教形而上学（新柏拉图主义），塑造了中世纪思想。
线索：存在与生成；理性与感官；一与多；自然（physis）与习俗（nomos）；德性与幸福（eudaimonia）；命运与责任。

## 本时代内的学习顺序（初学者）
1. 通过柏拉图读苏格拉底：《申辩篇》《克力同篇》《欧绪弗洛篇》。
2. 微缩版的前苏格拉底问题：先读概览，再读赫拉克利特对巴门尼德（残篇＋注疏），然后德谟克利特。泰勒斯、毕达哥拉斯：只读简短的二手介绍。色诺芬尼与阿那克萨戈拉只需了解到地图层面：色诺芬尼开启了对诸神的批判，阿那克萨戈拉则为第3步所读的《斐多篇》那段文字作了铺垫。
3. 柏拉图的体系：《斐多篇》（选读）→《理想国》卷一–二、卷六–七→《会饮篇》。
4. 亚里士多德的回应：《尼各马可伦理学》卷一–二（及卷十），辅以四因说／《形而上学》的导读概览。
5. 以犬儒派为桥梁：第欧根尼·拉尔修《名哲言行录》卷六。
6. 对话中的希腊化治疗学派：伊壁鸠鲁→斯多亚派→怀疑派（后者攻击前两者）。
7. 普罗提诺最后读（《九章集》I.6，再 V.1）：它以柏拉图和亚里士多德为前提。然后在地图层面了解晚期新柏拉图主义者，以波菲利关于属与种的三个问题（《导论》〔*Isagoge*〕开篇）收尾，由此交接给波爱修斯。
习惯：为希腊术语备一页词汇表——本原（archē）、逻各斯（logos）、幸福（eudaimonia）、心灵安宁（ataraxia）、悬置（epochē）、自然／习俗（physis/nomos）、理念（Form）、目的（telos）。

## 过度简化清单
- 泰勒斯：本原是始源性的原理，而不是字面意义上的 H2O 化学。
- 毕达哥拉斯：没有任何定理能确切地归于他；他在世时是以灵魂问题上的宗教导师闻名的（SEP）。
- 赫拉克利特：流变受逻各斯支配；河流之喻是转述，并非原话。
- 巴门尼德：他提出的是一个后继者不得不回应的论证，而不只是对显而易见之事的否认。
- 德谟克利特：原子是不可切割的、是论证出来的，而不是被发现／观察到的现代原子。
- 苏格拉底 ≠ 柏拉图对话的整体（早期与晚期不同；色诺芬、阿里斯托芬的记载也不同）。
- 柏拉图的理念：是解释性原理，在《巴门尼德篇》中受到他本人的批评。
- 亚里士多德的中道：不是“凡事适度”；幸福（eudaimonia）是贯穿一生的繁盛活动。
- 伊壁鸠鲁派 ≠ 纵欲。
- 斯多亚派 ≠ 无情感的压抑。
- 怀疑派并不主张一无所知。
- 犬儒派 ≠ 现代意义上的愤世嫉俗；那个“缸”是大陶罐（pithos）。
- 普罗提诺 ≠ 含混的神秘主义／厌世；流溢等于依赖，质料等于匮乏，而非邪恶的创造。
