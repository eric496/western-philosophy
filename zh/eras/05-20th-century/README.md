# 20世纪至今（1900 – ）

**简体中文** | [English](../../../eras/05-20th-century/README.md)

## 时代概览：分析哲学与欧陆哲学之分

这些标签是事后追认的、大略的划分——有用，但不要按字面理解。

- 分析哲学（主导于英国、美国、澳大拉西亚、斯堪的纳维亚）：源自弗雷格的新逻辑，以及罗素与摩尔在剑桥对英国唯心主义的反叛。方法：把问题拆成小块，精确界定术语，逐步检验论证；典范学科是逻辑、数学、自然科学。其疑虑是：宏大的谜题乃是松散语言造成的混乱——把语言澄清，谜题便消解或变得可回答。产品：短小、论证密集的论文；语言哲学、心灵哲学、逻辑哲学、科学哲学；后来又有严谨的政治哲学（罗尔斯）。
- 欧陆哲学（主导于德国、法国，此名出自英国人的视角）：源自康德、黑格尔、马克思、尼采，其后是胡塞尔的现象学。方法：从内部描述亲历的经验；历史地阅读观念——观念是时间、社会、权力的产物，需要诠释（诠释学）或揭露（谱系学、批判）。其疑虑是：超然的、无时间性的观点并不存在；思想者身处历史、语言、身体之中。产品：篇幅长、难度高的著作；现象学、存在主义、批判理论、结构主义/后结构主义。
- 为何硬化：地理与灾难——维也纳学派在石里克遇害（1936年）与纳粹崛起后星散；卡尔纳普与费格尔移居国外（赖兴巴赫柏林小组出身的亨普尔在美国与他们会合），以分析的方式重塑了美国科学哲学。海德格尔、法兰克福学派的流亡者、战后法国则发展出欧陆一脉。双方字面意义上有着不同的祖先（弗雷格/罗素 对 黑格尔/尼采/胡塞尔）。
- 注意事项：这一分裂关乎起点与风格，而非国籍或智力。维特根斯坦是身在剑桥的奥地利人；波普尔是维也纳学派的维也纳批评者；波伏娃为两边所读；安斯康姆既是维特根斯坦的译者，又是分析的德性伦理学复兴的开创者。最优秀的人物都是桥梁。
- 一句话概括本世纪：分析哲学问"我们能说什么，说得清楚而真实？"；欧陆哲学问"身处历史与权力之中、做着述说的那个生物，其处境是怎样的？"——最有趣的工作发生在两者的碰撞之处。

## 分析哲学一脉

逻辑先行：弗雷格的新逻辑 → 罗素与摩尔反叛英国唯心主义 → 早期维特根斯坦的图像说为这场运动给出了它关于清晰性的理想 → 维也纳学派把清晰性变成一项纲领（意义即证实） → 艾耶尔把它输出给英语读者 → 晚期维特根斯坦与赖尔从内部消解了这一纲领（语言游戏、范畴错误） → 奎因移除了它的两条教条 → 科学哲学（波普尔反对维也纳学派，继而库恩反对波普尔）与语言哲学成为增长领域 → 罗尔斯在分析的语汇内部复兴了实质性的政治哲学，安斯康姆与富特则复兴了德性伦理学。

## 现象学/存在主义一脉

家族谱系：胡塞尔创立现象学 → 海德格尔（助手/继承人）把它改造为关于存在的哲学 → 萨特与波伏娃（两人都研习过他们）把它变为法国存在主义 → 阿伦特（师从胡塞尔、海德格尔，博士学位于雅斯贝尔斯门下）把它转向政治。海德格尔与胡塞尔决裂；波伏娃修正萨特；阿伦特以对出生的专注回应海德格尔对死亡的专注。

## 批判理论、后结构主义、伦理学复兴

马克思、弗洛伊德与韦伯，被制度化：法兰克福研究所（创立于1923年）把哲学与社会研究结合 → 在纳粹统治下流亡 → 霍克海默与阿多诺追问启蒙自身为何会转为统治（文化工业） → 马尔库塞把这一批判带给新左派 → 哈贝马斯在交往而非生产的基础上重建它。法国一脉并行展开：结构主义那被去中心化的主体 → 福柯关于权力/知识在监狱、诊所与性中的谱系学 → 德里达对文本所依托的二元对立的解构。与此同时，在英语世界，安斯康姆1958年的宣言与富特的自然主义复兴了德性伦理学——一个欧陆尺度的问题（人应当如何生活？）以分析的工具被提出。

## 本时代内的学习顺序（五遍，不按年代）

第一遍 友好的入口：罗素《哲学问题》 → 萨特《存在主义是一种人道主义》+《禁闭》（No Exit），波伏娃《含混的伦理》 → 库恩《科学革命的结构》 → 波普尔《猜想与反驳》第1章（然后就波普尔对库恩展开争论）。
第二遍 语言：艾耶尔第1、6章（实证主义的英语通俗版） → 在指导下读早期维特根斯坦《逻辑哲学论》选段 → 晚期维特根斯坦《哲学研究》§§1–133。这一弧线本身就是分析哲学的故事。地图层面：艾耶尔之后读卡尔纳普；读奎因《经验论的两个教条》，然后读塞拉斯、戴维森、普特南与刘易斯。
第三遍 经验/生存：胡塞尔《笛卡尔式的沉思》+指南（扎哈维） → 海德格尔《基本著作》（Basic Writings），再在指导下读《存在与时间》选段 → 带着这套机制重读萨特/波伏娃，加上《第二性》（导论 + 第二卷开头，2010年译本）。地图层面：杜波依斯与法农论注视与双重意识，然后读作为波伏娃继承者的伊利格瑞、克里斯蒂娃与巴特勒。
第四遍 政治/权力（把对立的诸种透镜加以对照）：罗尔斯《作为公平的正义：正义论新论》（Restatement）（公平） → 阿伦特《人的境况》第I、V部分，再把《艾希曼在耶路撒冷》放回语境（复数平等者之间的行动） → 法兰克福学派"文化工业"（作为统治的文化） → 福柯《规训与惩罚》开头 +《性史》第一卷（制度/自我内部的权力）。把罗尔斯→阿伦特→福柯对照着读，比单独读任何一个都学到更多。地图层面：哈贝马斯（审议民主，反对福柯）与哈特（作为规则的法律，罗尔斯的背景）。
第五遍 硬核 + 重建：德里达《延异》（"Différance"）+《致日本友人的信》，再读《论文字学》选段 → 安斯康姆《现代道德哲学》+ 富特的电车问题/《自然的善》（Natural Goodness）开头——这一时代就此交棒给当代伦理学。德勒兹在地图层面与德里达并读（条目 + SEP；不要先读《千高原》）。

## 过度简化（通论）

- "分析哲学 = 冷冰冰的逻辑/科学；欧陆哲学 = 诗意的胡言"同时漫画化了两者（分析哲学产生了罗尔斯/安斯康姆；欧陆哲学产生了胡塞尔那门严密的经验科学）。差别在于问题与方法，而非严肃程度。
- 另见上文各人物的注意事项。
- 被压平的年代细节：《逻辑哲学论》德文版1921年 / 英文版1922年；波普尔《研究的逻辑》（Logik）1934年，但英译本1959年才出；《启蒙辩证法》1944年流传，1947年出版；《第二性》法文版1949年，完整英译本迟至2010年。
