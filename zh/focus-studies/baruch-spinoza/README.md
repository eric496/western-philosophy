## 人物简介

巴鲁克·斯宾诺莎（Baruch Spinoza）——在他出生会众的葡萄牙语中是本托（Bento），在他著作的拉丁语中是本尼狄克（Benedictus）——活了四十四年：他在阿姆斯特丹的葡萄牙犹太学校中接受将来成为拉比的教育，二十三岁时被该会众以现存最严厉的绝罚令之一逐出，此后在租来的房间里以磨制透镜为生，谢绝了一所大学的教席，只以自己的名字出版过一本书，身后把杰作留在抽屉里、由朋友取出刊行。这部哲学在极端性上与这段人生相称。《伦理学》以几何学顺序论证，从少数几个定义出发，论证出唯一的实体——神，或自然，*Deus sive Natura*（神即自然）——万有都是它的样态，以必然性从神的本性流出，正如三角形的性质从其本质流出。心灵与身体是同一事物在两种属性之下的显现；任何事情都不可能不是如此这般；终极因是人的虚构；自由不是对必然性的豁免，而是对必然性的理解，其果实是理智地爱神。《神学政治论》（1670）匿名出版、随即遭禁，把同样的理智运用于圣经与国家，奠定了现代圣经批判的基础，并为思想自由作出了早期的、激进的论证。在他的时代，"斯宾诺莎主义者"是一种指控；一个半世纪之内，黑格尔却能宣称：要么是斯宾诺莎主义，要么根本没有哲学。

## 为何值得数周研读

除了本库人物条目所给的画像之外，有三个理由。第一，**整体性**：《伦理学》是近代早期哲学中最完整的单一体系——形而上学、知识论、情感心理学、伦理学与宗教哲学都从一组定义出发、在一条链条中被推导出来——因此它是观察一部哲学如何像一台没有松动零件的机器那样运转、并学会定位"你在何处再也无法跟上"的那个确切前提的最佳训练场。第二，**位置**：斯宾诺莎是笛卡尔与启蒙运动之间的枢纽。他比笛卡尔本人更认真地对待笛卡尔自己的实体定义，把三类实体坍缩为一类；他身后几乎一切——德国的重新发现、泛神论之争、现代自然主义、心身二元属性论、当代情感理论——都要经过他的工作坊。第三，**这场复兴是活生生的**：近四十年的研究（柯利的版本、英语世界对情感与政治著作的重新解读）使斯宾诺莎可以说是他那个世纪被最活跃地重新诠释的人物，因此一次深入研读所面对的是真实而未决的问题——泛神论者还是无神论者、未知属性是否连贯、第五部分的"心灵的永恒"——而不是一座封存的纪念碑。

## 档案导览

- [01-life-and-times.md](01-life-and-times.md)——在他所处世界中的人生：阿姆斯特丹的改宗者会众、学校与商行、1656年的*谢雷姆*（cherem）及其理由何者可知、何者不可知、磨镜人的独立生活、朋友圈、被婉谢的教席、莱布尼茨的来访，以及逝世与身后之书；附带年表。
- [02-works-and-texts.md](02-works-and-texts.md)——每一部重要著作，按本档案阅读它们的顺序，附应使用的版本与译本以及应避免的版本与译本。
- [03-system-and-concepts.md](03-system-and-concepts.md)——作为建筑的体系：实体、属性、样态、*努力*（conatus）、情感、自由——都以他自己的术语加以界定，附人物专属词汇表与已知的内在张力。
- [04-arguments.md](04-arguments.md)——论证核心：主要论证以编号前提重构，每一论证附其最强的反驳与最佳的回应。
- [05-conversations.md](05-conversations.md)——对话中的斯宾诺莎：身后的笛卡尔、迈蒙尼德与霍布斯；身旁的莱布尼茨；前方的黑格尔、德国的重新发现与现代人。
- [06-reception-and-debates.md](06-reception-and-debates.md)——一个被绝罚者如何成为"哲学家中的王子"：臭名昭著的一个世纪、泛神论之争、现代复兴、活生生的学术争论，以及完整形态的常见误解。
- [07-study-plan.md](07-study-plan.md)——逐周工作计划：带章节目标的阅读、检查点、重构练习、媒体材料与结业论文。
- [08-bibliography.md](08-bibliography.md)——档案之外的注释书目：版本、从入门书到专著的二手文献、参考工具与媒体。
- [cards.tsv](cards.tsv)——本档案的[Anki](https://apps.ankiweb.net)卡组：按本库标准格式制作的论证卡与概念卡，供[FSRS](https://docs.ankiweb.net/deck-options.html)队列使用。

## 学习计划概览

本库的[学习路径](../../learning-path.md)在**第三阶段**（近代早期至康德）把斯宾诺莎作为*核心*人物：通读《伦理学》第一部分（配指南）、选读第二部分、选读第四与第五部分，《神学政治论》作概览式阅读。本档案把这一核心处理深化为完整处理。[07-study-plan.md](07-study-plan.md)给出一个**为期7周、约40小时预定学习（把每日卡组队列计入则总计约47小时）的计划**：通读《伦理学》全书（在本库逐命题的第一部分指南基础上推进，而不是重复它）、认真研读《神学政治论》——其圣经诠释方法与政治章节都全文研读、而非概览——展示体系如何形成的早期著作、展示它如何大声思考的书信，以及《政治论》选读。它按学习路径的每周节奏运行：先读原典，重构先于评论，每日FSRS队列由本档案的卡片供养。它在学习路径到达斯宾诺莎之处接入第三阶段；这些学时叠加在第三阶段预算之上，一如专题学时一贯如此，计划文件逐周列出了账目。
