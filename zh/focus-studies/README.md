# 专题研读——一位哲学家，深入探究
**简体中文** | [English](../../focus-studies/README.md)

文库中的条目为每一位人物提供了一幅扎实、细致的肖像。**专题研读**则是再深入一个层次：一份关于单一位哲学家的完整多文件档案，专为数周的专门学习而构建——一位认真的读者真正了解这位思想家所需要的一切，汇集在一处。

## 新增一份档案

档案逐一按哲学家添加，遵循 [TEMPLATE.md](TEMPLATE.md) 中的蓝图。也可以为尚无文库条目的人物建立专题研读，此时先撰写条目，再在其基础上构建档案。

## 一份专题研读包含什么

每份档案位于 `focus-studies/<philosopher-slug>/`，包含：

| 文件 | 内容 |
|---|---|
| `README.md` | 档案首页：人物速览、为何重要、如何使用本档案、学习计划概览、通往一切内容的链接 |
| `01-life-and-times.md` | 深度传记与历史语境：生平、环境、师承与对手、书信往来与转折点、一份带日期的年表 |
| `02-works-and-texts.md` | 著作全览，附导读：每部著作论证了什么、何时阅读、使用（与避开）的版本与译本、档案的阅读顺序 |
| `03-system-and-concepts.md` | 作为体系的思想：核心概念以人物自身的术语界定、该人物专属的术语表、各部分如何连接、张力所在之处 |
| `04-arguments.md` | 每一个主要论证以编号前提重构，各附标准反驳与最佳回应——学术争议标注为争议 |
| `05-conversations.md` | 对话中的人物：他们回应谁、他们的同时代人、谁回应他们，以及向前延伸的遗产线索——链接到文库的条目、回应链与[主题](../themes.md) |
| `06-reception-and-debates.md` | 接受史与当下的争议：学派的形成与破裂、学术论争的现状、完整形态的标准误解 |
| `07-study-plan.md` | 可执行的学习计划：按[学习路径](../learning-path.md)的节奏逐周安排、带章节目标的主要阅读、对应的播客节目与讲座、合上书的检查点、重构提示、一篇结业论文，以及一份"你能做到以下事情时即算完成……"的掌握清单 |
| `08-bibliography.md` | 注释书目：主要版本、从初级到高级的最佳二手文献、SEP/IEP 文章，以及附链接的已核查媒体清单 |
| `cards.tsv` | 一副人物专属的 [Anki](https://apps.ankiweb.net) 卡组（论证与概念），采用与 [`study/cards/`](../study/cards/README.md) 相同的制表符分隔格式，供 [FSRS](https://docs.ankiweb.net/deck-options.html) 队列使用 |

深度标准：一份档案各文件合计通常有 **15,000–30,000 词**——数倍于文库条目——准确性达 SEP/IEP 水平。本库的既定规则通篇适用：争议呈现为争议、约定俗成的日期保留"c."、一手文本的引文简短且注明出处（较长的摘录仅取自经核查的公有领域译本，译者具名）、美式英语。

## 音频伴读

每份档案还有其五个内容文件的**朗读音频版**——`01` 生平与时代、`03` 体系与概念、`04` 论证、`05` 对话、`06` 接受与论争——以便在阅读时间不足时聆听。朗读依照档案文本本身（标记、表格与链接杂讯一律剥除；引文以自然方式读出——"第一部分，命题十四"，而不是"E1P14"）。`02`（版本指南）、`07`（清单式的计划）与 `08`（文献出处）不朗读：它们是参考工具，不适合聆听。

音频文件作为可下载的资源发布在本仓库的 [Releases 页面](https://github.com/eric496/western-philosophy/releases)（标签：前三份档案为 `focus-audio-v1`，康德与维特根斯坦为 `focus-audio-v2`，柏拉图为 `focus-audio-v3`），因为仓库本身只存放文本。每份档案的 `README.md` 都载有**音频伴读**一节，列出其五集的时长与下载链接，因此属于一份档案的那组音频始终可以从档案本身找到。

## 专题研读如何与文库的其余部分相衔接

专题研读是一次深入的支线旅行，而非替代。它建立在人物的文库条目（该条目仍是快速肖像）之上，复用 [`study/`](../study/) 中已有的任何著作级指南而不重复它们，将其卡片加入学习路径所运行的同一个 Anki 系统，并在其学习计划中申明自身的课时成本——这些课时*叠加*在学习路径为该人物所属阶段所设的预算之上。专题研读的自然时机，是学习路径推进到该人物的时候；档案的学习计划会说明它在何处接入。
