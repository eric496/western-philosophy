# 专题研读模板——蓝图
**简体中文** | [English](../../focus-studies/TEMPLATE.md)

本文件规定了当一位哲学家被加入 `focus-studies/` 时要构建什么。它是给构建者的规格说明，而不是要抄进档案的文件。每份档案都针对其人物、从研究出发全新撰写——下面的文件集与标准是固定的；内容是人物自己的。

## 文件夹与命名

- 文件夹：`focus-studies/<slug>/`，其中 `<slug>` 与该人物条目的文件名（不含扩展名）一致（例如 `immanuel-kant`、`simone-de-beauvoir`）。文库中的分组条目（例如安斯康姆与富特），若被分别提出申请，则每人一份档案；若被共同提出申请，则在分组 slug 之下建一份联合档案。
- 文件：`README.md`、`01-life-and-times.md`、`02-works-and-texts.md`、`03-system-and-concepts.md`、`04-arguments.md`、`05-conversations.md`、`06-reception-and-debates.md`、`07-study-plan.md`、`08-bibliography.md`、`cards.tsv`。对于语料格外庞大的人物，一个文件可以拆分（例如 `04-arguments.md` 拆为两部分），但绝不可合并取消——上面的文件集是最低限度。

## 逐文件规格说明

### README.md（档案首页，约 800–1,200 词）
用一段话写出该人物；为何这位思想家值得数周的学习；档案的地图（每个文件一行，带链接）；学习计划概览（周数、课时、在何处接入学习路径）；通往文库条目、该人物著作的任何 `study/` 指南，以及档案卡组的链接。

### 01-life-and-times.md（约 2,000–3,000 词）
完整的传记，并附上其身处的历史世界：教育、师承、对手、庇护人与审查者、诸著作的写作缘起、晚年生活与死亡、身后出版的命运（如相关）。以一份带日期的年表作结。凡立足于传说或晚出史料的说法，都标注出来（全库规则：呈现记录本身，记录稀薄之处加以限定）。

### 02-works-and-texts.md（约 1,500–2,500 词）
每一部重要的著作，按档案将要阅读它们的顺序：一部著作一条——日期（本库的出版标注方式）、它论证了什么、它的难度、它在人物思想发展中的位置。每部著作都指名要用的版本与译本：用哪一个、避开哪一个、以及为什么（与学习路径的版本裁定保持一致；路径未作规定的，由档案裁定并申明如此）。在适用之处提醒手稿/遗稿方面的问题（例如，人物从未出版过的一部"书"，要标注为此类）。

### 03-system-and-concepts.md（约 2,500–4,000 词）
其架构：人物的核心问题、承重概念先按人物自身的术语界定然后才谈批评、这些概念如何相互咬合、该体系已知的内部张力。包含一份人物专属的术语表（10–25 条），格式与 `glossary.md` 相同，并把人物自己的用法与后来的教科书用法区分开来。

### 04-arguments.md（约 3,000–5,000 词）
论证的核心。每一个主要论证——一位重要人物预计有 6–12 个——以各条目中"标志性论证"部分的风格，用编号前提重构：重构本身、文本依据（著作与章节）、最强的标准反驳，以及最佳回应（人物自己给出的就用他自己的，他没有给出的就用文献中的，并如此标注）。关于一个论证究竟是什么的诠释争议，要呈现为争议，并点名主要的读法。

### 05-conversations.md（约 1,500–2,500 词）
向后：这位思想家所回应的传统与具名人物，并指出具体的接触点。横向：同时代人、书信往来、公开论争。向前：学生、学派与具名的回应者——每一位都链接到该人物的文库条目，以便档案接入本库的回应链，而不是重述它们。有一节追踪该人物在 `themes.md` 九大问题中的轨迹：他们在每条相关的线索中出现在何处。

### 06-reception-and-debates.md（约 1,500–2,500 词）
按时代划分的接受史（直接的反响、十九世纪、二十世纪、当下）、自命为该人物传人的学派与运动，以及以问题现状陈述的当下学术争议——谁持有什么立场、依据什么证据。以完整形态的标准误解作结（条目中的"应避免的误读"是摘要；这里是长版），以及记录所不支持的关于其生平的任何神话。

### 07-study-plan.md（工作文件）
一份完整、可排期的计划，规模与人物相称（通常为 4–8 周，按学习路径的每周节奏；档案的 README 诚实申明总课时，包括媒体与复习时间）：
- 逐周表格：主要阅读（著作、章节、所指名版本中的页码目标）、配合阅读的档案文件、带节目/讲座标识的媒体作业（播客与课程若在第 6 轮研究中已核查过则用之；任何新内容在布置之前必须核查）。
- 每周检查点：合上书的问题，附答案，或指向档案中解答该问题的章节。
- 按学习路径的节律（+2 天 / +1 周 / +3 周，连续再学习）设置的重构提示，以及卡片的安排：随着该人物的学习周开始，档案的 `cards.tsv` 进入 [Anki](https://apps.ankiweb.net) 的 [FSRS](https://docs.ankiweb.net/deck-options.html) 队列。
- 一篇结业论文（800–1,200 词），附 3–5 个要求通览整份档案的题目；若该人物是学习路径的核心人物，再加上与阶段关卡文章的关系。
- 以掌握清单作结："当你能做到以下事情时，你就完成了……"——8–12 条以学习路径的风格写成的"能做"陈述。

### 08-bibliography.md（约 1,000–1,500 词）
带注释、分层级：(1) 一手文本与版本；(2) 最先要读的二手著作，按顺序；(3) 高级与专门文献；(4) 参考资料——[SEP](https://plato.stanford.edu/) / [IEP](https://iep.utm.edu/) 文章及链接、[PhilPapers](https://philpapers.org/) 的分类指引、相关的期刊或指南类著作（如《剑桥指南》之类，如其存在）；(5) 附网址的媒体清单（播客系列与节目范围、讲座课程、有声书）。每条注释都说明该条目是做什么用的，以及已知的时间或金钱成本。

### cards.tsv
人物专属的卡组，采用 `study/cards/` 的格式：恰好 3 个以制表符分隔的字段（正面、背面、标签）；论证卡片取自 `04-arguments.md`，概念卡片取自 `03-system-and-concepts.md`；标签为 `figure::<slug> type::argument|concept focus::<slug>`。导入与复习遵循 `study/cards/README.md`（FSRS）。

### 音频伴读（作为 release 资源发布）
从定稿的档案文本朗读五个内容文件（`01`、`03`、`04`、`05`、`06`）。语音准备：剥除标记、链接（保留链接文字）、表格与页脚导航；把章节符号拼读出来（"section 52"）；把人物的引证惯例展开为语音（斯宾诺莎的 E1P14 → "part one, proposition fourteen"；尼采的著作缩写在节号之前展开）；引文与限定语照原文一字不易地保留。全程使用同一种嗓音与语速。各集作为 GitHub Release 资源发布（每批音频一个 release，资源命名为 `<slug>-<file-stem>.mp3`），档案 README 中的表格链接到每一集的下载网址。档案的 `README.md` 增加一节**音频伴读**，列出五集及其时长。若某个已朗读的文件后来被大幅修订，重新录制该集，并更新所列时长。

## 标准（本库一切规则适用，另加以下各条）

1. 先研究，后写作：档案建立在文库条目、任何已有的 `study/` 指南、SEP/IEP 文章，以及对日期、版本与媒体可得性的定点核查之上——与本库审计轮次同样的核查纪律。无法核实的事实，或加以限定，或略去，绝不抹平。
2. 档案中的任何内容都不与文库条目、指南或学习路径相矛盾；档案更深入的研究若更正了它们，则在同一次提交中也在那些文件里作出更正，并在提交说明中标注出来。
3. 所有内部链接可解析；档案在同一次推送中登记进 `focus-studies/README.md` 的名录。
4. 上面的词数是导引，不是配额——对这位人物的完整性比凑一个数字更重要。
