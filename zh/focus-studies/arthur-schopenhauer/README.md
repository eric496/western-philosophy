## 人物速览

阿瑟·叔本华（Arthur Schopenhauer）构建了对19世纪哲学中乐观、理性主义主流的最完整的替代方案。他从康德出发——我们经验的世界是表象，由空间、时间和因果性构成——并声称在康德的墙上找到了一道裂缝：我们每个人都不仅从外部、作为对象认识自己的身体，还从内部、作为*意志活动*（willing）认识它。他把这种双重知识推广到整个自然界，得出结论：一切事物的内在本质、物自体，是**意志**（Will）：一种单一的、盲目的、无目的的努力，它在引力与磁力中客体化自己，一如在食欲与野心中。由这一个形而上学主张，其余整个体系以不寻常的必然性展开。因为意志活动即匮乏，匮乏即痛苦，存在便由苦难构成，只能在向无聊的钟摆摆动中得到暂时的缓解。因为个体化只是意志*显现*的方式，同情——把他人的苦难当作自己的苦难来感受——是道德唯一真正的根基。因为努力在例外情况下能够转向自身，便有了真实而狭窄的出口：审美观照（在其中音乐居于最高位）、同情，以及对意志的禁欲式否定——叔本华顶住他那个世纪的每一种正统（基督教的与黑格尔派的）为之辩护。他在三十岁之前写完了这一切，此后四十年被人无视，直到六十多岁时凭借那些他一度视为副业的随笔成名。

## 为何值得数周研读

叔本华是罕见的体系哲学家，同时又是一位伟大的文体家；也是一位罕见的悲观主义者，其阴郁是论证出来的，而非表演出来的。三点使他值得一份完整的专题档案，而不只是本库（已经相当可观的）人物条目。其一，*建筑学上的清晰*：很少有体系能让你看着每一种学说——认识论、形而上学、美学、伦理学、宗教哲学——从一个原理推导出来，也很少有体系如此适合逐个论证地重构。其二，*辐射范围*：他是一个枢纽人物。在他身后站着康德、柏拉图和《奥义书》——他把这三者并列为自己的三个源头；在他身前站着尼采、瓦格纳、弗洛伊德（他公开承认驱动力概念先于自己出现）和现代主义文学血脉的大部分。其三，*对困难之处的诚实*：这个体系有真实的紧张——一位康德主义者何以能声称认识物自体本身，一种同情伦理学如何安置在一种利己主义努力的形而上学之内——而叔本华的文本为学生提供了以全力提出这些反对意见所需的一切。简言之，他是理想的第一个专题研读对象：中心是一本书，周围是一个完整的体系，而他的一生又戏剧化地呈现了过早正确的代价。

## 学习计划速览

本库的[学习路径](../../learning-path.md)在**第四阶段**（19世纪：体系、反叛、社会）遇到叔本华，并像对待大多人物一样，以*节选*层级处理他：读一遍著名的书与章节。本档案把这种节选处理升级为**完整的体系**。[07-study-plan.md](07-study-plan.md)给出一个**约6周的计划：约30小时的计划研读，外加约5–6小时的每日 Anki 复习——总计约35小时**——涵盖以剑桥译本通读《作为意志和表象的世界》第一卷、其背后的学位论文、伦理学随笔、第二卷的关键补充章节，最后通读一遍《附录与补遗》——按学习路径的每周节奏运行（先读原著，先重构后读评论，每日 FSRS 队列由本档案的卡片喂养）。它在原节选作业的位置接入第四阶段：当学习路径走到叔本华时做这个专题，其结业论文可一兼二职地计入该阶段的要求。这些学时叠加在第四阶段的预算之上——专题研读的学时一向如此；计划文件逐周列出了账目。
